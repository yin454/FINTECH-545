# FINTECH 545 — Assignment 3

## How to run


Run the entire assignment:

```bash
python assignment3.py
```

This prints the answers for each problem and regenerates the figures, tables, and `results.json`.


## Conventions

- Use arithmetic returns except when the question asks for geometric annualization.
- Report VaR and ES as positive loss amounts.
- Use calendar days / 365 for Problem 1 and 255 trading days for Problem 3.
- Use fixed random seeds for Monte Carlo and bootstrap reproducibility.
- In Problem 2, binomial steps line up with the two cash-dividend dates.
