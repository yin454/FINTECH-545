# FINTECH 545 — Functional Tests 8.1–13.9


## How to Run

1. Open a terminal in this folder (the folder containing `test_functional.py`).
2. Install the required Python packages:

   ```bash
   python -m pip install numpy pandas scipy pytest
   ```

3. Run all tests:

   ```bash
   python -m pytest test_functional.py -v
   ```

The expected result is **25 passed**.
